# Agent Workspace Guide

This repository root is an orchestration workspace, not a single application.

## Directory Map

- `frontend/` - Next.js frontend cloned from `git@github.com:vedlct/Waste_Service.git`.
- `backend/` - Laravel backend intended for the admin panel, CMS, and API.
- `docs/` - project requirements, API notes, admin-panel decisions, deployment notes, and other long-lived context.

## Frontend Notes

- Work from `frontend/` for frontend tasks.
- Key files and folders:
  - `frontend/package.json` - scripts and JavaScript dependencies.
  - `frontend/src/` - application source.
  - `frontend/public/` - static assets.
  - `frontend/AGENTS.md` - Next.js-specific agent instructions generated by the frontend project.
- Common commands:
  - `npm install`
  - `npm run dev`
  - `npm run build`
  - `npm run lint`

## Backend Notes

- Work from `backend/` for Laravel/admin/API tasks.
- Key files and folders:
  - `backend/composer.json` - PHP dependencies and Laravel scripts.
  - `backend/app/` - application code.
  - `backend/routes/` - web and API route definitions.
  - `backend/database/` - migrations, factories, seeders, and local SQLite file if used.
  - `backend/config/` - framework and app configuration.
- Common commands:
  - `php8.4 /usr/local/bin/composer install`
  - `php8.4 artisan serve`
  - `php8.4 artisan test`
  - `php8.4 artisan migrate`
  - `npm install`
  - `npm run dev`

## Environment Notes

- The backend was installed with `php8.4 /usr/local/bin/composer create-project laravel/laravel backend`.
- The backend is Laravel 13 and requires PHP `^8.3`; use `php8.4` for Artisan and Composer commands unless the system default PHP is changed.
- The initial Laravel post-install migration warned that the SQLite PHP driver is missing for PHP 8.4. Install/enable the SQLite extension or configure another database before relying on migrations.

## Docs Workflow

- Check `docs/README.md` first when looking for project context.
- Put requirements and decisions in `docs/` instead of burying them in chat history.
- Update this root `AGENTS.md` when new top-level directories, services, or important workflows are added.

## Working From Root

- Do not assume root-level package commands exist.
- Choose `frontend/` or `backend/` first, then run commands from that directory.
- Avoid broad scans of `node_modules/`, `vendor/`, build outputs, and generated caches unless the task specifically requires them.

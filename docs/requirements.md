# Requirements

This file is a starting point for the project requirements.

## Product Goal

Build a frontend waste service website/application backed by a Laravel admin panel and API.

## Frontend

- Source lives in `../frontend`.
- The cloned repository is named `Waste_Service` on GitHub, but the local directory is intentionally `frontend`.
- Treat the current frontend implementation as the source of truth for existing UI, routes, and copy until fuller requirements are documented here.

## Backend

- Source lives in `../backend`.
- Laravel will serve as the admin panel, content management system, and API provider for the frontend.
- Exact CMS entities, roles, permissions, and API endpoints still need to be defined.

## Open Questions

- What content should be manageable from the admin panel?
- What frontend pages need dynamic content from the backend?
- What user roles are needed for the admin panel?
- What authentication method should the API use?
- What database should be used in local, staging, and production environments?
